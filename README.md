# IRON & IVORY — Men's Grooming & Beard Care Studio

> **"Sharp Looks. Refined Rituals."**

A commercial-grade, multi-page HTML5, CSS3, and Vanilla JavaScript website template created for high-end **Men's Grooming & Beard Care Studios**, Master Barbershops, Beard Apothecaries, and Grooming Membership Clubs.

---

## 🌟 Key Highlights & Design Identity

- **Brand Personality**: Sharp, Masculine, Confident, Refined, Contemporary, Craft-Focused (Quiet confidence, editorial barbershop aesthetic).
- **Theme Engine**: Built-in Light & Dark mode switch with `localStorage` persistence and `prefers-color-scheme` support.
- **Mandatory Navbar & Behavior**: Sticky header with working hover dropdowns (`Home ▾` -> Home 1, Home 2; `Services ▾` -> Haircuts, Beard Trims, Hot Towel Shave, Grooming Treatments, Service Details), Theme Toggle, and prominent Book Appointment CTA.
- **Mobile Responsive**: Fully responsive across mobile (320px–425px), tablet (768px–1024px), and desktop (1280px–2560px+) with zero horizontal scroll or clipped menus.
- **Production Ready**: 12 complete HTML pages, zero empty placeholder sections, zero lorem ipsum, zero broken links or broken images.

## ⚡ Interactive Features Included

1. **Universal Booking Modal**: Accessible from the navbar button and CTAs on all 12 pages. Automatically populates service selection.
2. **Interactive Form Validation**: Live input validation with real-time success notification popups.
3. **Category Filtering Engine**: Smooth category tabs on `services.html`, `products.html`, and `gallery.html`.
4. **Gallery Lightbox**: Click any portfolio image to launch a full-screen lightbox modal with captions and ESC key closing.
5. **Back-to-Top Button**: Smooth scrolling back to top when scrolling down long pages.

---

## 🚀 Quick Start Guide

1. Clone or download the repository into your web root or local environment.
2. Open `index.html` in any web browser to explore the live website.
3. To customize branding or colors, open `assets/css/style.css` and edit the `:root` CSS variables.
4. Detailed documentation is included in `documentation/index.html`.
