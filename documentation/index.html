Template Overview

IRON & IVORY is a commercial-grade, fully responsive HTML5/CSS3/Vanilla JS website template meticulously engineered for high-end Men's Grooming Studios, Master Barbershops, Beard Care Brands, and Grooming Membership Clubs.

Theme Standards Built with zero framework lock-in, crisp typography hierarchy, CSS root variables for instant light/dark mode switching, and zero missing image fallbacks.

Color & Layout Tokens

Theme & RTL Engine

The template features built-in Light/Dark Mode switching and full Right-to-Left (RTL) layout support for languages like Arabic and Hebrew, toggled via dedicated navbar controls and persisted in localStorage: 

:root {
  --bg-primary: #0D0D0F;       /* Dark Obsidian */
  --bg-secondary: #141417;     /* Charcoal Dark */
  --accent-gold: #C5A059;      /* Muted Gold Accent */
  --text-primary: #F4F2ED;     /* Warm Ivory Text */
}

/* RTL Layout Mode */
html[dir="rtl"] {
  /* Flips alignment, paddings, margins, icons, and drawer navigation automatically */
}
Interactive Features

JavaScript Modules

  • Theme Switcher: Automatically persists user choice in localStorage under key 'iron_ivory_theme'.
  • Appointment Booking Modal: Opened by any HTML element containing class .trigger-booking-modal. Pass pre-selected service using data-service="Service Name".
  • Category Filters: Applied dynamically to elements with .filterable-item and data-category="...".
